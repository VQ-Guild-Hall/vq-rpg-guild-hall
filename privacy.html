Privacy Policy

Guild Hall · Last updated 8 November 2026

Who this applies to

Guild Hall is a private, personal automation project with a single user: its owner. It is not offered to the public, and no other person's Google account is connected to it.

What data the app accesses

With the owner's explicit consent through Google's sign-in, Guild Hall may access the following data from the project's own Google account:

  • Gmail messages, to read and summarise them for the owner
  • Google Drive files, Docs and Sheets, to read and create documents for the owner
  • Google Calendar events, to read and add entries for the owner

How the data is used

The data is used only to provide features to the owner, such as summaries, briefings, documents and reminders. It is not used for advertising, it is not sold, and it is not used to build profiles of anyone.

Sharing

Google user data is not shared with or transferred to third parties, except to AI model providers to process a request the owner made, and only as far as needed to complete that request. No human other than the owner reads the data.

Storage and security

Data is processed on a private server controlled by the owner. Access credentials are stored as encrypted secrets and are never published. Data that is no longer needed is deleted.

Google API Services User Data Policy

Guild Hall's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from the Google account's security settings, under third-party apps with account access.
